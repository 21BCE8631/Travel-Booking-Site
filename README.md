# FlyEasy ✈️

FlyEasy is a modern, responsive flight booking landing page built using **HTML and CSS**.  
It showcases airline deals, features, pricing plans, and a clean UI optimized for both desktop and mobile devices.

## 🌟 Features
- Responsive navigation bar with hamburger menu
- Hero section with promotional call-to-action
- Feature highlights for airline services
- Pricing section with recommended plan
- Fully responsive layout using CSS Grid & Flexbox
- Smooth hover effects and modern UI design

## 🛠️ Technologies Used
- HTML5
- CSS
